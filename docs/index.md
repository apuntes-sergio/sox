Apuntes del módulo de **SOX** (Sistemes Operatius en Xarxa) para el ciclo formativo de grado medio de **SMX** (Sistemes Microinformàtics en Xarxa)

En este espacio encontrarás los apuntes básicos sobre el módulo, que constará de los siguiente Bloques y Unidades Didácticas:


1. Sistemas Operativos Privativos 

En este primer bloque del curso vamos a aprender los conceptos básicos sobre sistemas operativos para servidores y vamos a instalar y configurar sistemas privativos.

- UD1. Introducción a los Sistemas Operativos de servidor
- UD2. Instalación de sistemas operativos de servidor privativos: Windows Server
- UD3. Gestión del dominio en Windows Server. Usuarios y grupos
- UD4. Gestión de recursos compartidos en Windows Server
- UD5. Gestión de directivas en Windows Server
- UD6. Gestión avanzada del dominio en Windows Server


2. Sistemas Operativos Libres

En este bloque vamos a instalar sistemas libres y vamos a realizar tanto integración de sistemas GNU/Linux con sistemas Windows como programación de scripts para la administración de sistemas libres

- UD7. Instalación de sistemas operativos libres
- UD8. Sistemas Hibridos: Linux Server e integración básica con Windows
- UD9. Scritps para la administración de sistemas libres
